# UI 设计预览（浏览器）

这是**可交互的高保真界面预览**，不是文字说明稿。

## 本地打开

双击或用浏览器打开：

`diy-stall-miniprogram/design-preview/index.html`

支持切换「首页 / 商品详情 / 管理-商品」，顶部色块可改主题色（与小程序 CSS 变量一致）。

## 在线预览（GitHub）

将 `main` 或你的分支名替换进链接：

```
https://htmlpreview.github.io/?https://raw.githubusercontent.com/1044987073/zq/cursor/diy-miniprogram-ui-f2de/diy-stall-miniprogram/design-preview/index.html
```

## 与 Cursor Canvas 的区别

- **本 HTML**：真实布局与配色预览，可改色，任意浏览器可开。
- **Cursor Canvas 链接**：在 Cursor 里打开的配套线框/说明；已更新为带手机界面示意，但**真机级预览请以本 HTML + 微信开发者工具为准**。
