# 公园 DIY 摆摊小程序 · UI 设计规格 v1

> **给即时设计用**：按本章在 js.design 搭稿。开发以即时设计定稿 + `tokens.json` 为准。

## 设计原则

- 风格：亲子、户外、手工；自然绿主色，暖色强调价格与 CTA。
- 用户端：手机 **375×812**（@1x），底部 Tab 四栏。
- 管理端：桌面 **1440×900**，左侧导航（小程序内为独立页面，布局可略简化）。

## Design Token

见同目录 **`tokens.json`**。即时设计中绑定 TDesign 品牌色变量与之一致。

| Token | 默认值 | 用途 |
|-------|--------|------|
| primary | `#2D6A4F` | 导航、主按钮、Tab 选中 |
| primaryLight | `#52B788` | Hero 渐变、辅助强调 |
| secondary | `#D8F3DC` | 标签底、步骤序号底 |
| accent | `#F4A261` | 价格、营业额数字 |
| background | `#F7F9F8` | 页面背景 |
| surface | `#FFFFFF` | 卡片 |
| text | `#1B4332` | 标题正文 |
| textMuted | `#52796F` | 辅助说明 |
| radiusMd | `16` | 卡片圆角（px） |
