# 在即时设计中搭出「真实 UI 稿」（约 1–2 小时）

按顺序做，做完即得到 **可分享的即时设计链接**，再进入开发阶段。

## 0. 准备

- 账号：[js.design](https://js.design) 注册/登录（个人免费版即可）。
- 打开本仓库 **`design/screens/`** 下 PNG（视觉参考，需用组件重绘）。
- 打开 **`SPEC-v1.md`** 对照画板清单。

## 1. 引入 TDesign 组件库

1. 首页 → **资源广场** → 搜索 **TDesign**。
2. **使用** 以下资源（免费）：
   - [TDesign Web 端组件](https://js.design/community?category=detail&id=625d594eba0a72e19014f0fb&type=resource)（管理端）
   - 资源广场搜索 **TDesign 移动端** / **TDesign 小程序** 相关库（用户端）
3. 官方汇总：[TDesign 设计资源 → 即时设计](https://tdesign.tencent.com/source)

## 2. 新建文件与画板

1. **新建** → 设计文件 → 命名 `公园DIY摆摊-v1`。
2. 按 `SPEC-v1.md` 创建画板（快捷键 F），命名如 `U1-首页`、`U2-项目列表`…
3. 用户端画板统一 **375×812**；管理端 **1440×900**。

## 3. 搭用户端 U1 首页（模板）

1. 从组件库拖 **导航栏**（或顶栏 Frame + 文字「首页」），背景色 `#2D6A4F`，字白色。
2. Hero 区域：圆角 16 的 Frame，填充 `#2D6A4F`，内文：
   - 标题 20px 粗体：公园手工 DIY 小摊  
   - 副文案 13px：砸石膏 · 涂面具 · 把创意带回家  
   - Tag「营业中」+ 时间文案  
3. 标题「主推体验」→ **Cell/卡片** 一行：左图 56×56，右文案 + 价格色 `#F4A261`。
4. 「全部项目」重复 2~3 个 Cell。
5. 底部 **TabBar** 四项：首页 / 项目 / 套餐 / 关于（选中项 `#2D6A4F`）。
6. 将 `screens/U1-home.png` 置于底层 50% 透明度对照，对齐后 **隐藏或删除参考图**。

其余 U2–U5、A1–A5 同样：参考对应 PNG + `SPEC-v1.md` 文案。

## 4. 主题色

在即时设计 **样式/变量**（或 TDesign 自带 Token）中设置：

- Brand / Primary → `#2D6A4F`  
- 与 `tokens.json` 保持一致  

## 5. 分享定稿

1. 右上角 **分享** → 开启链接分享 → 复制 URL。  
2. 把链接填进 `SPEC-v1.md` 顶部「定稿链接」处（或发给开发）。  
3. 在 `DESIGN-WORKFLOW.md` 勾选「设计定稿确认」。

## 6. 然后才开发

开发只对照：

- 即时设计链接（视觉）  
- `tokens.json`（Token）  
- `SPEC-v1.md`（页面与字段）  

仓库内 `diy-stall-miniprogram` 将按你的定稿链接做 UI 走查修订（定稿前代码仅为草案）。

## 常见问题

**Q：能不能代我做好即时设计文件？**  
A：需要在你本机登录即时设计操作；云端无法代登账号。本指南 + 参考图是为减少你搭稿时间。

**Q：和蓝湖的关系？**  
A：即时设计可单独分享；若研发坚持用蓝湖，可从 Figma/Sketch 导出再上传蓝湖，或直接用即时设计研发模式看标注。
