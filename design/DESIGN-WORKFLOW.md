# 设计先行 → 再开发（推荐流程）

你要的顺序应是：

```text
① 即时设计完成 UI 稿（可分享链接、可评审）
        ↓ 你确认「设计定稿」
② 开发对照设计稿实现（小程序 / 可选 H5）
        ↓
③ UI 走查（页面与设计稿逐屏对比）
```

当前仓库里 **微信小程序代码** 与 **Vue 演示** 属于 **② 的提前样例**，在你没有即时设计定稿前，应视为「参考实现」，**不以它们为最终视觉标准**。定稿后以即时设计链接 + 本目录 `SPEC-v1.md` + `tokens.json` 为准。

---

## 你需要完成的第 ① 步（在即时设计）

1. 登录 [即时设计](https://js.design)。
2. 新建设计文件，命名建议：`公园DIY摆摊-小程序-v1`。
3. 从资源广场 **使用 TDesign 移动端 + Web 端** 组件库（与开发组件一致）。
4. 按 **`SPEC-v1.md` 画板清单** 搭界面（尺寸、文案、结构已写好）。
5. 需要参考视觉时，把 **`screens/`** 下 PNG **拖进画布** 作参考图，再用 TDesign 组件重绘（不要只留截图）。
6. 右上角 **分享协作** → 复制链接，发给开发（或自己留存）。
7. 可选：**发布至资源广场** 获得公开浏览链接。

详细点击步骤见 **`JSDESIGN-STEP-BY-STEP.md`**。

| 输入 | 用途 |
